# Provenance

This skill is an original OpenAR Skill Hub workflow written for the
Research Outputs studio (M-OUT OUT-06). It references, but does not
carry, the design-system analyses of
`VoltAgent/awesome-design-md` at commit
`c7c1bada4eda972236d124e06ee58df129a9266b` (MIT), subdirectory
`design-md/`.

What was taken from upstream: nothing verbatim except the facts in
`references/design-md-index.md` — the per-brand slugs, analysis names,
file sizes, sha256 hashes, and one-line descriptions quoted (some
truncated) from each `DESIGN.md` frontmatter. The `DESIGN.md` bodies are
not copied into this entry; the workflow fetches one body only after the
user picks it, and verifies it against the recorded hash.

Upstream's per-brand `README.md` files (which point at the project's own
website) are not referenced. No logos, photographs or font files are
carried. The upstream MIT license is reproduced in
[`THIRD_PARTY_LICENSES.md`](THIRD_PARTY_LICENSES.md).
