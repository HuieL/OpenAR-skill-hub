# Provenance

Original OpenAR content, written by the Craft Suite maintainers and handed
to the hub as `SKILL.md` and `references/roundtrip.md`. The hub carries both
files byte-for-byte; their sha256 values match the handoff manifest.

The skill describes how an agent works with Craft Suite's installed
components through the host's existing controls. It grants nothing. The
session's live extension-action listing decides what an agent may invoke,
and human-only Craft actions stay human-only.
