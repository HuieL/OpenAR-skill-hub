# Original → proposal → editable result → returned source

## Establish the actual input

Work inside the selected project's Craft Suite. Use a component already
supported by the installed host, with its approved adapter available. Import
only the user's selected supported original; retain its protected revision
and provenance. Recover the original through the existing original-read and
download controls when needed. Do not substitute an export for the original
or scan other directories to discover assets.

The available operation can be a deliberately finite recipe. Ask the current
UI/schema what it accepts and state that scope instead of promising arbitrary
native-file editing. Examples include a selected image crop, one supported
text replacement, Light exposure or Sound gain. Do not invent a general
command interface around a bounded action.

## Generate and continue editing

Use the component's proposal control for the requested operation. Keep the
actual Task identity and its current settlement. A model proposal is not a
saved result: use the existing Finish/publication control only for that
settled proposal and its unchanged input. Bind the resulting preview and
editable source to their actual saved revisions and inherited original.

Create or reattach the existing workcopy with the exact source/export pins.
Edit its supported source using the available verified engine/native path.
Verify that workcopy and commit through the existing CAS save controls.
If the input changed, refresh and review the current revisions; do not force
a save by replacing the expected revision. Preserve the protected original
and any required media companion. Light's original PNG companion stays
immutable; Sound's converted media companion has its own identity and must
not be described as byte-identical to the original audio.

A source-only commit may retain the old preview. Confirm the current saved
source revision, identify that retained preview explicitly, and use the
returned-source reader to render/query the new source. Ask a question whose
answer requires the edited content. Check the actual returned observation,
source ContextRef, source revision and fresh render/projection revision.
A text projection hash and a PNG/WAV/PDF hash identify different bytes.

## Resume without replaying a completed write

If a request or Finish response was lost, first inspect the existing Task,
current saved source/export, workcopy and provenance. A timeout is an unknown
outcome, not evidence that publication failed. Reattach/recover the existing
saved pair when the host confirms it. Do not launch a second producer or
repeat Finish to repair the browser view. If the existing host cannot
reconcile that state, report the unresolved checkpoint and keep its data.

Read only currently authorized files. After disabling/revoking the project
instance, a previous ContextRef, download descriptor or remembered path does
not restore permission. Use the normal installation/lifecycle flow when the
user wants the capability restored; do not edit host storage or grants.
